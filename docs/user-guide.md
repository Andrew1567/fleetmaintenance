# Посібник користувача

Консольний застосунок FleetMaintenance веде облік пробігу автопарку, визначає, яким машинам час на технічне обслуговування, і планує замовлення на ТО.

## 1. Запуск

```
dotnet run --project src/FleetMaintenance.App
```

Команду виконують з кореня репозиторію: застосунок читає теку `data` у поточній теці. Іншу теку можна передати першим аргументом: `dotnet run --project src/FleetMaintenance.App -- шлях/до/data`. Одразу після запуску з'являється меню:

```
1) Зареєструвати пробіг
2) Запланувати обслуговування
3) Змінити стан замовлення
4) Звіт: машини, що потребують ТО
5) Знайти ТЗ
6) Додати ТЗ
0) Вихід
Ваш вибір:
```

Для відтворюваного прикладу нижче дату зафіксовано змінною середовища (інакше береться поточна дата):

```
FLEET_TODAY=2026-11-02 dotnet run --project src/FleetMaintenance.App      # bash
$env:FLEET_TODAY="2026-11-02"; dotnet run --project src/FleetMaintenance.App   # PowerShell
```

Нижче показано лише діалог (після двокрапки йде те, що вводить користувач); меню між діями не повторено.

## 2. Сценарії

### 2.1. Зареєструвати пробіг (UC-01)

```
Ваш вибір: 1
Номер ТЗ: MH7831EM
Новий пробіг, км: 292100
Пробіг ТЗ MH7831EM: 292100 км.
```

### 2.2. Запланувати обслуговування (UC-02)

```
Ваш вибір: 2
Номер ТЗ: AB2637CC
Вид ТО (OilChange, Brakes, Inspection): OilChange
Замовлення №1, вартість 1725.00 грн.
```

### 2.3. Змінити стан замовлення (UC-03)

```
Ваш вибір: 3
Номер замовлення: 1
Дія (Start, Complete, Cancel): Start
Замовлення №1: виконується.
```

Завершення замовлення записує ТО в історію ТЗ, і потреба в цьому виді ТО зникає зі звіту:

```
Ваш вибір: 3
Номер замовлення: 1
Дія (Start, Complete, Cancel): Complete
Замовлення №1: виконано.
```

### 2.4. Звіт «Машини, що потребують ТО» (UC-04)

```
Ваш вибір: 4
Машини, що потребують ТО, станом на 2026-11-02
Номер     Модель                ТО       Стан             км  міс        грн
AB2637CC  Mercedes Sprinter     мастило  прострочено   14455    9    1725.00
AC1000CX  Mercedes Sprinter     мастило  прострочено   21665   10    1725.00
AK8552OT  Renault Master        мастило  прострочено   23497    9    1725.00
AP4263EC  Volvo FL              мастило  прострочено   34008    8    2208.00
...
Разом: 78 рядків, 228012.75 грн
```

Спершу йдуть прострочені (`прострочено`), потім ті, що скоро потребуватимуть ТО (`скоро`); у межах стану — за номером і видом ТО. Колонка `км` показує пробіг після останнього ТО цього виду, `міс` — повні місяці.

### 2.5. Знайти ТЗ (UC-05)

```
Ваш вибір: 5
Текст (номер або модель, Enter — усі): sprinter
Тип (Car, Van, Truck, Enter — усі): 
Знайдено: 2.
AB2637CC  Mercedes Sprinter  Van  184312 км
AC1000CX  Mercedes Sprinter  Van  243623 км
```

### 2.6. Додати ТЗ (UC-06)

```
Ваш вибір: 6
Номер (AA1234BB): KB0001AA
Модель: Skoda Fabia
Тип (Car, Van, Truck): Car
Пробіг, км: 12000
Додано ТЗ №61: KB0001AA.
```

## 3. Повідомлення про помилки

| Повідомлення | Що означає | Що робити |
|---|---|---|
| Помилка: Номер має формат AA1234BB (латинські літери). | номер не збігається з форматом | ввести дві латинські літери, чотири цифри, дві латинські літери |
| Помилка: ТЗ AA1234BB не знайдено. | такого номера немає в даних | перевірити номер або додати ТЗ (пункт 6) |
| Помилка: Пробіг: ціле число від 0 до 5000000. | пробіг не є невід'ємним цілим числом | вводити лише цифри, без пробілів і крапок |
| Операцію відхилено: Пробіг … км менший за поточний … км. | одометр не може показувати менше | перевірити значення; помилку введення виправити новим, більшим числом |
| Помилка: Обслуговування ще не потрібне. | за пробігом і датою інтервал вичерпано менш ніж на 80 % | дочекатися, поки ТЗ з'явиться у звіті |
| Помилка: Для цього ТЗ уже є активне замовлення такого виду. | замовлення ще не завершене чи скасоване | завершити (Complete) або скасувати (Cancel) наявне |
| Операцію відхилено: Подію … не можна застосувати в стані …. | перехід заборонений таблицею станів | перевірити стан замовлення; з Done і Cancelled дій немає |
| Помилка: Замовлення №… не знайдено. | немає замовлення з таким номером | перевірити номер |
| Помилка: Тип ТЗ / Вид ТО / Дія: допустимі значення … | введено значення поза переліком | вибрати одне зі значень, що надруковані в повідомленні |
| Помилка даних: Файл … пошкоджено … (код виходу 2) | JSON-файл у теці data не читається | відновити файл із резервної копії |

## 4. Де лежать дані й резервна копія

Дані — у теці `data`: `vehicles.json` (ТЗ з історією ТО) і `orders.json` (замовлення). Журнал подій — `logs/fleet.log` (час, рівень, сценарій, повідомлення; без персональних даних). Щоб зробити резервну копію, скопіюйте теку `data` на зупиненому застосунку, наприклад `cp -r data data-backup-2026-11-02`; для відновлення скопіюйте її назад.
